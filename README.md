# Mobile Manufacturing Sales & Production Analysis

## Project Overview
This project analyzes mobile manufacturing, production, sales, revenue, and inventory data to generate useful business insights and support data-driven decision-making.

## Objectives
- Analyze total mobile production and sales.
- Calculate revenue and identify sales trends.
- Compare production quantity with sales quantity.
- Analyze unsold stock and inventory.
- Track monthly production and sales performance.

## Tools Used
- Microsoft Excel
- Power BI 

## Dataset
The project uses mobile manufacturing data containing production, sales, pricing, and related business information.

## Key Metrics
- Total Production
- Total Quantity Sold
- Total Revenue
- Average Sales
- Unsold Quantity
- Inventory Utilization
- Monthly Sales and Revenue Trends

## Project Workflow
1. Raw Data
2. Data Cleaning
3. Production Analysis
4. Sales Analysis
5. Revenue Analysis
6. Inventory Analysis
7. Monthly Trend Analysis

## Business Insights
The analysis helps identify sales performance, revenue trends, production efficiency, and unsold inventory to support better business planning.
